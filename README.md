# Jumbo Add-on Maker

Editor visual con bloques para crear add-ons de Minecraft Bedrock.

## Objetivo
Crear mobs, bloques, items y comportamientos sin programar, usando una interfaz visual pensada para móvil.

## Versión 0.1
Esta primera versión incluye:

- Interfaz web inicial.
- Blockly para programación visual.
- Bloques para crear un mob básico.
- Generación de JSON de comportamiento para Minecraft Bedrock.
- Botón para descargar el JSON generado.

## Tecnologías

- HTML
- CSS
- JavaScript
- Google Blockly
- Minecraft Bedrock JSON

## Estructura

```txt
assets/
  icons/
  textures/
  models/
src/
  app.js
index.html
style.css
```
